详细配置步骤图解

第一阶段：路由器基础设置

步骤1：刷入增强型固件
1. 访问路由器管理界面（192.168.1.1）
2. 导航至【高级】-【管理】-【固件升级】
3. 上传下载好的Merlin固件（如R7000380.700.chk）
4. 等待约5分钟完成刷机

专业提示：刷机过程中切勿断电，建议使用有线连接操作

步骤2：开启必要功能
1. 启用JFFS分区（用于存储脚本文件）：
【系统管理】-【系统设置】-【Format JFFS partition at next boot】选"是"
2. 开启SSH远程管理：
【系统管理】-【系统设置】-【Enable SSH】选择"LAN only"

第二阶段：科学上网核心配置

方案A：Shadowsocks透明代理（推荐）
1. 通过SSH连接路由器（用户名为admin，密码为管理密码）
2. 安装Entware环境：
bash opkg update && opkg install shadowsocks-libev 3. 配置ss-redir：
json { "server":"your_server_ip", "server_port":443, "password":"your_password", "method":"aes-256-gcm", "timeout":300, "fast_open":true } 4. 设置iptables规则实现全局代理：
bash iptables -t nat -A PREROUTING -p tcp -j SHADOWSOCKS

方案B：OpenVPN客户端配置
1. 下载服务商提供的.ovpn配置文件
2. 在路由器界面进入【VPN】-【OpenVPN客户端】
3. 导入配置文件并启用"自动重连"选项
4. 设置策略路由（仅特定设备走VPN）：
bash ip route add default via $VPN_GW dev tun0 table 100 ip rule add fwmark 0x1 table 100

第三阶段：智能分流设置

为避免国内网站也走代理导致速度下降，需要配置智能分流：

  1. 安装dnsmasq-full替代原DNS服务：
    bash opkg install dnsmasq-full
  2. 配置国内IP段直连：
    bash wget -O /jffs/configs/china_ip.txt https://raw.githubusercontent.com/17mon/china_ip_list/master/china_ip_list.txt
  3. 设置分流规则：
    bash for ip in $(cat /jffs/configs/china_ip.txt); do iptables -t mangle -A SHADOWSOCKS -d $ip -j RETURN done

高级优化技巧

1. 双WAN负载均衡

通过USB 3.0接口接入4G网卡作为备用线路，当主线路故障时自动切换：

常见问题解决方案

Q1：连接VPN后网速明显下降
A：尝试以下步骤：
1. 更换加密方式（如将AES-256改为CHACHA20）
2. 测试不同服务器节点
3. 检查是否开启硬件加速（【高级】-【LAN配置】）

Q2：部分设备无法科学上网
A：检查：
1. 设备是否被加入了策略路由例外列表
2. 本地DNS是否被污染（建议改用DoH）

Q3：如何实现Netflix跨区观看
A：需要：
1. 确认VPN支持流媒体解锁
2. 在路由器设置DNS覆写：
bash nvram set custom_dns="8.8.8.8,1.1.1.1" nvram commit

FAQ

V2Ray 的 WebSocket + TLS 配置有哪些优势？
WebSocket + TLS 可以伪装成普通 HTTPS 流量，增强抗封锁能力。适合高封锁环境，结合域名伪装和策略组，可实现高安全性和稳定的网络访问体验。
Mellow 与 Clash 的核心区别是什么？
Mellow 采用基于透明代理的架构，适合路由或系统级流量重定向，而 Clash 更偏向规则式应用代理。Mellow 的灵活性更高，但配置复杂；Clash 则兼顾易用性与功能扩展性。
Shadowrocket 的分流规则如何实现广告拦截？
通过配置规则，将广告域名或请求路径匹配到黑名单策略，使请求直接阻断或重定向到本地地址。这样用户浏览网页或使用应用时可自动屏蔽大部分广告内容。
QuantumultX 如何实现按端口和协议分流？
QuantumultX 支持按 TCP、UDP、端口及应用协议分流流量，结合策略组选择最优节点。这样可以为游戏、视频和广告屏蔽提供最佳网络体验，提高访问速度和稳定性。
何时应选择 VLess 而非 Vmess？
若追求更轻量、高性能的连接且采用外部 TLS 或 XTLS 进行加密，建议选择 VLess。VLess 去除了内嵌加密，能更好配合现代传输（XTLS/Reality）实现更低延迟与更好扩展性。
VMess 配置 TLS+WebSocket 有哪些性能优势？
TLS+WebSocket 可伪装 HTTPS 流量，增强抗封锁能力，同时降低被封检测风险。结合策略组和节点延迟检测，可保证访问速度和连接稳定性，适合视频和游戏场景。
Mellow TUN 模式与 SOCKS5 代理有什么区别？
TUN 模式拦截系统 IP 层流量，实现全局代理；SOCKS5 代理通常只影响指定应用。TUN 更适合全局加速，如游戏、视频和浏览器流量，提高网络稳定性和覆盖范围。
Hysteria2 的 QUIC 传输在高丢包环境下表现如何？
QUIC 基于 UDP，具备拥塞控制和重传机制，在高丢包环境下仍能保持稳定连接。Hysteria2 利用 QUIC 特性，使流量高效传输，延迟低且稳定性好。
Surfboard 支持按应用分流流量吗？
支持。Surfboard 可通过策略组和规则文件将不同应用的流量分配到指定节点，保证游戏、视频和浏览器流量走最优节点，提高访问速度和网络稳定性。
Mellow TUN 模式的全局代理作用是什么？
TUN 模式拦截系统 IP 层的所有流量，实现全局代理效果。相比 SOCKS5 只作用于特定应用，TUN 可覆盖游戏、视频和浏览器流量，保证全系统科学上网体验稳定顺畅。
